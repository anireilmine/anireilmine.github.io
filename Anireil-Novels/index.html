Инструкция по запуску

Простые шаги для чтения визуальных новелл на компьютере и мобильном телефоне.

Инструкция для PC (Windows)

  1. Скачайте архив через Telegram-бота или с зеркал Mega / Google Диск.
  2. Распакуйте архив в отдельную папку через архиватор 7-Zip или WinRAR.
  3. Найдите запускаемый файл с расширением .exe (например, game.exe).
  4. Запустите игру. Приятного чтения!

Инструкция для Android

  1. Если в карточке новеллы указан файл .apk — просто скачайте и установите его на телефон.
  2. Если новелла в архиве (движок Ren'Py), скачайте бесплатный эмулятор JoiPlay из Google Play.
  3. Распакуйте архив в память телефона и укажите файл игры внутри приложения JoiPlay.
